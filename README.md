# Monate Water
Monate - Premium Bottled Water E-commerce Site.

Pure, refreshing hydration delivered fast via WhatsApp checkout. Still, sparkling, and flavored waters for South Africa.

## Features
- Responsive design (mobile-first)
- LocalStorage cart
- WhatsApp ordering (+27 81 764 4450)
- Vanilla HTML/CSS/JS - no dependencies

## Quick Start
1. Open `index.html` in browser
2. Add waters to cart
3. Checkout via WhatsApp button

Live demo ready!
